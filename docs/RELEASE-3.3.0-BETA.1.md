# Aulama Anime TV 3.3.0 Beta 1（搶先版）

> 搶先版供公開測試，正式版發佈前內容仍可能調整。

## 更新重點

### 全新首次進入頁面

- 重新設計登入／遊客模式選擇頁：兩張選擇卡片清楚說明「使用 Aulama ID 登入」與「免登入使用」的分別，焦點位置固定，不會因輪播作品名稱長短而移動。
- QR Code 登入頁加入入場動畫、狀態淡入淡出及「返回」鍵提示，QR Code 生成速度更快。

### 電影感預覽播放

- 焦點停留約 3 秒即開始準備預覽（原為約 7 秒），等待期間封面會緩慢推近。
- 預覽影片會由封面平滑溶入，聲音同步淡入；按任何按鍵時影片與聲音會平滑淡出，不再突然切換。
- 預覽播放時簡介會讓位給影片，並加入柔和暗角，標題與作品列在明亮畫面上仍然清楚。
- 首頁、時間表及詳情頁的相關動漫預覽統一使用以上效果。

### 更流暢的遙控器操作

- 全新彈簧動畫系統：焦點移動、海報浮起、按鈕回饋均可隨時改變方向，手感更順滑自然。
- 首頁、我的片庫及相關動漫：選中的海報會輕微浮起，作品名稱淡入而非突然出現；長按方向鍵會連貫滑動，不再逐張停頓。
- 詳情頁：主要「播放」按鈕更醒目；按鈕聚焦時平滑放大及轉色。
- 詳情頁在集數與相關動漫之間上下移動時，改為平滑捲動及資訊淡入淡出，取代原本整個畫面閃黑的過場。

### 首頁與我的片庫分工更清晰

- 首頁只保留一行「繼續觀看」，放在主打作品下面第一行：包括未看完的作品，以及已收藏、看過而又出了新一集的作品，按最近觀看排列。首頁不再重複顯示整個收藏列表。
- 我的片庫成為完整片庫，跟網頁版一樣按時間分組：觀看紀錄分為「最近觀看」、「一個月前」及「已看完」；我的收藏按最後觀看的年月分組（例如「2026年10月」），未看過的收藏歸入「未有觀看紀錄」。
- 每一行標題前加上「觀看紀錄」或「我的收藏」標籤，切換行時改用與首頁相同的彈簧過場，不再閃黑。

### 季度完結評分及推介

- 播完一季最後一集（作品已完結、而且已經播到片尾）時，會彈出評分視窗：用左右鍵揀星、按 OK 儲存，評分會同步到網頁版及推薦系統。
- 評分後（或選擇暫時唔評分）會推介最多 6 套下一套可以睇的作品（續作、同系列及個人推介），可直接打開詳情，或返回首頁。
- 只會在季度最後一集出現，平時每集播完仍然照舊自動播下一集；仍在連載中的作品播到最新一集亦不會彈出。已評分的作品會直接顯示推介。
- 最後一集片尾期間按返回鍵，亦會先顯示此視窗；再按返回鍵即回到詳情頁。需要登入 Aulama ID。

### 播放器

- 保留「跳過片頭」、「跳過片尾」及「下一集」＋「繼續播放」組合；「下一集」按鈕顯示將會播放的集數（例如「下一集・第4集」），倒數充能會帶一道流動光芒，充滿後自動播放下一集。
- 按鈕加大、文字加粗，出現時由下方滑入淡出，消失時淡出，不再突然彈出或消失；聚焦時帶輕微彈性放大。
- 片名改用圓體並加入頂部柔和暗角，明亮畫面下仍然清楚。

### 詳情頁

- 參考網頁版：年份、地區、類型以小標籤顯示，「已完結」／「連載中」及評分（★）以顏色標示。
- 有觀看紀錄時，主按鈕顯示「繼續 · 第N集」，按鈕底部有觀看進度條；下方提示「上次看到第N集 · 還剩 X 分鐘」。
- 每集按鈕底部顯示該集觀看進度，看完的集數一目了然（本機與雲端紀錄合併）。
- 新增「評分」按鈕（登入後），可隨時為作品評一至五粒星，與網頁版共用同一評分。

### 舊款電視效能

- 動畫只改變透明度、縮放及位移，避免逐格重新排版；移除部分整幅離屏合成，Android 5／6 電視盒子亦可保持流暢。

## 安裝

下載 Release 內的 `aulama-anime-tv-v3.3.0-beta.1.apk`，傳送到 Android TV、Google TV 或 Android 電視盒子覆蓋安裝即可。由舊版升級會保留原有 App 資料。

最低支援 Android 5.0（API 21）。
