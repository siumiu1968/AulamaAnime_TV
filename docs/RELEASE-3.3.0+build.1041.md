# Aulama Anime TV 3.3.0 正式修正版（build 1041）

App 顯示版本仍為 **3.3.0 正式版**，安裝編號提高至 **1041**。此打包取代最初的 3.3.0（1040），並保留原有 GitHub 發佈記錄。

## 修復

- 修正啟動時登入資料儲存介面的依賴解析，避免 App 開啟後立即退出。沿用原有加密儲存實作，保留原有登入及本機資料。
- 保留新版片庫 `cw:` 等作品 ID 的詳情及播放修復，以及 3.3.0-beta.1 的動畫、登入介面和片庫改進。
- 加入發佈前的 Android TV 實機模擬啟動檢查：安裝已簽署的 Release APK、開啟主畫面，並觀察程序及畫面持續正常，檢查通過才可發佈。

## 安裝

下載此發佈的 APK，直接覆蓋安裝；無需清除 App 資料。正式 APK 沿用原有簽署金鑰，安裝編號 1041 支援從 3.3.0-beta.1（1039）及最初的 3.3.0（1040）升級。

新版片庫作品仍需登入 Aulama ID，與網頁版的接口要求一致。

## 驗證

發佈流程必須通過 297 個單元測試、Release 組建、原有簽署憑證核對及官方 Android TV 系統上的 Release APK 啟動檢查。
