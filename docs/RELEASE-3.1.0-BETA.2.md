# Aulama Anime TV 3.1.0 Beta 2

## 測試重點

- 全新安裝時只顯示一次支援公告；按「知道了」後，本機會永久記錄，不會因日後更新再次出現。
- 更新視窗與首次使用公告按優先次序顯示，不會重疊或互相搶走遙控器焦點。
- 歡迎頁改用書面語與完整比例海報，並改善封面切換時的色彩過渡。
- 遊客可於用戶卡片登入 Aulama ID；介面語言、預覽播放及更新通道集中於同一張設定卡片。
- 更新通道改為單一橫向選項，可在正式版與搶先版之間切換。
- 更新下載加入逾時與失敗處理，更新提示預設聚焦「下載更新」。

## 驗證提示

此版本已通過單元測試與 Debug 組建；發布後仍應在實體 Android TV／Google TV 驗證遙控器焦點、下載安裝及長時間播放。
