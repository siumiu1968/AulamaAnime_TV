# Aulama Anime TV 3.3.0 正式版

此最初打包（1040）已由正式修正版 **3.3.0 build 1041** 取代。請從 [最新正式發佈](https://github.com/siumiu1968/AulamaAnime_TV/releases/latest) 下載，以修正啟動時的依賴設定問題。

以 3.3.0-beta.1 為基礎，保留動畫、登入介面、片庫分組、詳情頁及季度完結評分與推介的改進，並修復新版片庫作品無法載入的問題。

## 修復內容

- 修復 `cw:` 作品 ID 被送往只接受數字 ID 的舊接口而出現 `400` 錯誤，例如 `cw:3939`；只有純數字 ID 可使用舊接口，避免其他新格式 ID 再誤入舊路徑。
- 新版作品詳情使用與網頁版相同的 Aulama API，保留每集的 `webSectionId`，恢復主線路 A 的選集及播放地址解析。
- 多條主線路按來源分開顯示，保留各線路的集數順序及播放身份；後備線路繼續按實際可用集數顯示。
- 未登入時清楚提示先登入 Aulama ID；取消載入時停止播放地址解析。

## 安裝

下載 `aulama-anime-tv-v3.3.0.apk`，傳送至 Android TV、Google TV 或 Android 電視盒子覆蓋安裝。正式 APK 沿用原有簽署金鑰，保留原有 App 資料，並支援從 3.3.0-beta.1 升級。

最低支援 Android 5.0（API 21）。新版片庫作品需登入 Aulama ID，與網頁版的詳情接口要求一致。

## 驗證

發佈流程會執行全部單元測試、Release 組建及原有簽署憑證核對。修復包含相中作品三集的資料解析、多線路同名集數、無效或補位集數，以及原有數字 ID 和 `gg:` ID 的回歸測試。實體電視的播放仍需按裝置及網絡環境確認。
