# Aulama Anime TV 3.3.0

## 更新重點

### 全新首次進入頁面

- 重新設計登入／遊客模式選擇頁：兩張選擇卡片清楚說明「使用 Aulama ID 登入」與「免登入使用」的分別，焦點位置固定，不會因輪播作品名稱長短而移動。
- QR Code 登入頁加入入場動畫、狀態淡入淡出及「返回」鍵提示，QR Code 生成速度更快。

### 電影感預覽播放

- 焦點停留約 3 秒即開始準備預覽（原為約 7 秒），等待期間封面會緩慢推近。
- 預覽影片會由封面平滑溶入，聲音同步淡入；按任何按鍵時影片與聲音會平滑淡出，不再突然切換。
- 預覽播放時簡介會讓位給影片，並加入柔和暗角，標題與作品列在明亮畫面上仍然清楚。
- 首頁、時間表及詳情頁的相關動漫預覽統一使用以上效果。

### 更流暢的遙控器操作

- 全新彈簧動畫系統：焦點移動、海報浮起、按鈕回饋均可隨時改變方向，手感更順滑自然。
- 首頁、我的片庫及相關動漫：選中的海報會輕微浮起，作品名稱淡入而非突然出現；長按方向鍵會連貫滑動，不再逐張停頓。
- 詳情頁：主要「播放」按鈕更醒目；按鈕聚焦時平滑放大及轉色。
- 詳情頁在集數與相關動漫之間上下移動時，改為平滑捲動及資訊淡入淡出，取代原本整個畫面閃黑的過場。

### 舊款電視效能

- 動畫只改變透明度、縮放及位移，避免逐格重新排版；移除部分整幅離屏合成，Android 5／6 電視盒子亦可保持流暢。

## 安裝

下載 Release 內的 `aulama-anime-tv-v3.3.0.apk`，傳送到 Android TV、Google TV 或 Android 電視盒子覆蓋安裝即可。由舊版升級會保留原有 App 資料。

最低支援 Android 5.0（API 21）。
