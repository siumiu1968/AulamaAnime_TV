# Aulama Anime TV 3.1.0

## 更新重點

- 全新安裝時只顯示一次支援公告；按「知道了」後，本機會永久記錄，不會因日後更新再次出現。
- 更新視窗與首次使用公告按優先次序顯示，不會重疊或互相搶走遙控器焦點。
- 歡迎頁改用書面語與完整比例海報，並改善封面切換時的色彩過渡。
- 遊客可於用戶卡片登入 Aulama ID；介面語言、預覽播放及更新通道集中於同一張設定卡片。
- 更新通道改為單一橫向選項，可在正式版與搶先版之間切換。
- 搜尋支援模糊字詞、別名、繁簡名稱與日文原名，網站 API 暫時失效時會安全退回舊搜尋。
- 詳情頁支援主線路、後備 A 與後備 B，並改善遙控器焦點、長標題及失敗時切換線路提示。
- 更新下載加入逾時與失敗處理，更新提示預設聚焦「下載更新」。

## 驗證狀態

已通過 165 項單元測試、Release 組建，以及 Android TV 模擬器的首次公告、歡迎頁、用戶卡片與更新通道操作驗證。實體電視的下載安裝及長時間播放仍建議按實際網絡環境再作確認。
