# Aulama Anime TV 3.2.0

## 更新重點

- 首頁、發現、時間表、我的片庫與詳情頁全面改善遙控器焦點、動畫流暢度及預覽播放體驗。
- 播放線路與網頁版同步，支援主線路 A、主線路 B 繁中／簡中及可用後備線路。
- 改善 HLS 播放相容性、播放失敗回退、片頭片尾跳過提示及下一集操作。
- 收藏加入新集數提醒；更新中動漫按最近更新排序，已完結收藏按收藏時間排序。
- 首頁與我的片庫觀看紀錄改為最近觀看優先，並縮短預覽播放等待時間。
- 改善地區限制頁面與重新嘗試流程。

## 安裝

下載 Release 內的 `aulama-anime-tv-v3.2.0.apk`，傳送到 Android TV、Google TV 或 Android 電視盒子安裝即可。由舊版升級會保留原有 App 資料。

最低支援 Android 5.0（API 21）。
